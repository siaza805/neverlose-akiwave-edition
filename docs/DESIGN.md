# Design language

- Graphite surfaces with high-contrast text, muted labels and subtle borders
- Rounded shell (12px), section cards (8px) and tab selection (8px)
- Main window default size: 780x530, configurable through `CreateWindow(Size=...)`
- The sidebar contains **script-defined tabs only**; Theme Studio opens via the gear icon
- Theme Studio has a two-column preset gallery and scrollable customization controls
- Anime artwork is optional and uses an image asset ID supplied by the user

Screenshots were provided by the project user. This project is an independent community modification.
