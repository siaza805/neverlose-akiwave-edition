# Akiwave v5.2 — Design language

Preserve Neverlose's original structure; avoid decorative extra sidebar categories.

- **Shell:** compact dark graphite, 14px corners and thin live accent outline
- **Sidebar:** 202px width, higher contrast, 43px navigation items, active accent rail
- **Top bar:** separate panel surface and 2px accent underline, clear gear hitbox and theme badge
- **Sections:** two independently scrolling columns, 34px heading space, accent heading rail, outline and inner padding
- **Controls:** 37px labeled rows, 38px action buttons, softened hover state, readable 13px typography
- **Color-only Theme Studio:** real color swatches; seven presets, HEX customization, window transparency, Unload GUI
- **Motion:** direct, clamped pointer dragging with 6px threshold; no Tween races. Clicking must never move a window.

The source remains a reusable library; demos populate controls separately. There are no anime graphics.
